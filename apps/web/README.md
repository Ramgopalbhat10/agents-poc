# React + TypeScript + Vite + shadcn/ui

This is a template for a new Vite project with React, TypeScript, and shadcn/ui.

## Streaming setup
- `VITE_LANGGRAPH_API_URL` (default: `http://localhost:2024`)
- `VITE_LANGGRAPH_ASSISTANT_ID` (default: `orchestrator`)
- `VITE_STREAMING=false` to use the non-streaming fallback
